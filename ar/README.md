## 🕋 عن المشروع

**برنامج آيات (Ayat)** هو المحاكي الإلكتروني للمصحف الشريف المطور من قِبل **مشروع المصحف الإلكتروني بجامعة الملك سعود**. يُعد من أفضل وأشمل البرامج القرآنية المتاحة لأجهزة الحاسوب، حيث يقدم نسخة مصورة من مصحف المدينة المنورة مع خدمات تفاعلية مميزة مثل التلاوات، التفاسير، الترجمات، واختبارات الحفظ.

يهدف هذا المستودع إلى **تغليف وتحويل النسخة الخاصة بنظام ويندوز (x64) إلى صيغة AppImage مستقرة** لتسهيل تشغيل البرنامج على كافة توزيعات لينكس بكل سهولة ودون عناء ضبط المحاكيات.

---

## 🚀 لماذا حزمة AppImage؟

- **تشغيل محمول وفوري (Portable):** ملف واحد يعمل مباشرة على أي توزيعة دون الحاجة لخطوات تثبيت معقدة.
- **استقلالية التبعيات:** الحزمة مدمجة ومحزمة بكافة التبعيات ومحرك Wine المناسب، مما يضمن عمل البرنامج بغض النظر عن تحديثات النظام.
- **لا تتطلب صلاحيات جذرية (No Root Required):** يمكنك تشغيل البرنامج كمستخدم عادي دون الحاجة لاستخدام `sudo`.
- **جاهزية للاستخدام بدون إنترنت (Offline Ready):** تحتوي الحزمة مسبقاً على صفحات المصحف والتفاسير والترجمات دون الحاجة لتنزيلها مجدداً.
- **نظافة النظام:** لا يتم التعديل على ملفات النظام الأساسية، ويتم حفظ الإعدادات والملفات في المجلد الشخصي للمستخدم.

## 📦 المحتويات المضمنة داخل الحزمة

تتميز هذه الحزمة بكونها **مدمجة وشاملة مسبقاً (Pre-bundled)**، حيث تشتمل داخل ملف الـ AppImage على:

- 📖 **صفحات المصحف الشريف:** كامل صفحات مصحف المدينة المنورة بالرسم العثماني عالي الجودة مضمنة بالكامل للعمل فوراً بدون اتصال بالإنترنت.
- 📚 **التفاسير القرآنية المعتمدة:** تضمين حزمة التفاسير الرئيسية (تفسير السعدي، ابن كثير، القرطبي، الطبري، الجلالين، البغوي، وغيرها) لتعمل مباشرة دون الحاجة لتنزيل ملفات إضافية.
- 🌐 **تراجم معاني القرآن:** الترجمات القياسية المعتمدة لعدة لغات عالمية مضمنة داخل الحزمة.
- 🎧 **التلاوات الصوتية:** إمكانية تنزيل الملفات الصوتية والتلاوات الإضافية حسب رغبة المستخدم، حيث تُحفظ تلقائياً في مجلد المستخدم للوصول إليها دائماً.

## 📥 التحميل والتشغيل

### الخطوة 1: تحميل الحزمة
انتقل إلى صفحة **[الإصدارات (Releases)](https://github.com/HBI-Developer/ayat-appimage/releases)** في المستودع وقم بتحميل أحدث ملف بصيغة AppImage:
`Ayat-1.4-x86_64.AppImage`


### الخطوة 2: منح صلاحية التشغيل
افتح الطرفية (Terminal) في المجلد الذي يحتوي على الملف المحمل، ونفّذ الأمر التالي:

```bash
chmod +x Ayat-1.4-x86_64.AppImage
```

> **أو عن طريق الواجهة الرسمية:** اضغط بزر الفأرة الأيمن على الملف ⬅️ اختر **Properties** ⬅️ انتقل لتويب **Permissions** ⬅️ فعّل خيار **Allow executing file as program**.

### الخطوة 3: تشغيل البرنامج
انقر مرتين على الملف، أو قم بتشغيله عبر الطرفية:

```bash
./Ayat-1.4-x86_64.AppImage
```

## 🎨 دمج البرنامج مع قائمة التطبيقات (اختياري)

إذا كنت ترغب في إظهار برنامج آيات في قائمة التطبيقات الرئيسية مع الأيقونة الرسمية:

يمكنك استخدام أداة [AppImageLauncher](https://github.com/TheAssassin/AppImageLauncher) لدمج أي ملف AppImage تلقائياً بنقرة واحدة.

**أو يمكنك إنشاء اختصار يدوي (`ayat.desktop`):**

1. ضع الملف في مجلد البرامج الخاص بك (مثلاً `~/Applications/`).
2. أنشئ ملفاً باسم `~/.local/share/applications/ayat.desktop` وضمّن فيه المحتوى التالي:

```ini
[Desktop Entry]
Name=Ayat - المصحف الإلكتروني
Comment=برنامج آيات لجامعة الملك سعود
Exec=/path/to/Ayat-1.4-x86_64.AppImage
Icon=ayat
Terminal=false
Type=Application
Categories=Education;Religion;Utility;
```
*(تأكد من استبدال `/path/to/` بالمصار الفعلي للملف لديك).*

## 🛠️ التفاصيل التقنية ومسارات البيانات

- **محرك التشغيل:** يتم تشغيل مشغل Adobe AIR المدمج داخل بيئة Wine معزولة مخصصة ومضمنة بالكامل داخل حزمة الـ AppImage.
- **إدارة الخطوط (Font Handling):** تم إعداد البيئة لتستخدم الخطوط ذات الحقوق والملكية الفكرية (مثل `Georgia` و `Times` و `Verdana` و `Arial` و `Tahoma`) تلقائياً في حال وجودها في نظام التشغيل لدى المستخدم للحصول على أفضل جودة عرض، عوضاً عن الاعتماد على الخطوط البديلة فقط.
- **المحتوى والبيانات المضمنة:** ملف الـ AppImage يحتوي مسبقاً على بيانات المصحف كاملة والتفاسير المعتمدة والتراجم، ليكون التطبيق جاهزاً للعمل بدون إنترنت فور التشغيل الأول.
- **مجلد البيانات والإعدادات:**
  عند التشغيل لأول مرة، يقوم البرنامج بإنشاء بيئة عمل خفيفة في المسار التالي داخل مجلد المستخدم:
  `~/.local/share/ayat-appimage/`
- **الملفات والمواد الصوتية:**
  تُحفظ التفاسير والتلاوات المحملة لاحقاً في مجلد التطبيق المخصص، مما يسمح بالاحتفاظ بالمواد المحملة حتى عند نقل الحزمة أو تحديثها.

## ❓ حل المشاكل الشائعة (Troubleshooting)

### 1. لا يعمل الملف عند النقر المزدوج في التوزيعات الحديثة (Ubuntu 22.04+ / Debian 12)
قد تعود المشكلة لعدم وجود مكتبة FUSE 2. يمكنك تثبيتها عبر الأمر:

- **Ubuntu / Debian / Mint:**
  ```bash
  sudo apt install libfuse2
  ```
- **Fedora:**
  ```bash
  sudo dnf install fuse-libs
  ```
- **Arch Linux / Manjaro:**
  ```bash
  sudo pacman -S fuse2
  ```

### 2. إعادة ضبط إعدادات البرنامج
في حال حدوث أي خطأ في بيئة التشغيل وترغب في إعادة ضبط البرنامج كأنه يُشغّل للمرة الأولى، يمكنك حذف مجلد الإعدادات عبر الأمر:

```bash
rm -rf ~/.local/share/ayat-appimage
```
